# CivicPulse

Local issue reporting hub built with React.js, JavaScript, CSS, and HTML.

## Run

```bash
npm install
npm run dev
```

Open the URL shown in the terminal (usually http://localhost:5173).

## Features

- Submit and track civic issues
- Login / register
- Find and register private workers
- Agent dashboard with OTP resolution
- Dashboard filters, upvotes, comments
- Reviews and chatbot
